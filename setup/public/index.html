DockerAC setup

Install Server Manager, the Assetto Corsa server and plugins. Files are stored in the /data volume.

Sign in

The password is SETUP_PASSWORD, or the one printed in the container logs (docker compose logs).

Existing installation:

Upload only what you want to update: config, database and content are kept.

2 Assetto Corsa server

The free Server Manager needs the Kunos dedicated server. You'll find it in your game folder under steamapps/common/assettocorsa/server.

A dedicated account without Steam Guard is recommended. Credentials are only used for this installation and are not saved.
